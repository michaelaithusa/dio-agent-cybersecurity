# Fundamentos de Cibersegurança

Para qualquer análise de segurança, utilize estes conceitos como base:

- **Vulnerabilidade:** Uma fraqueza no código ou sistema que pode ser explorada.
- **Ameaça:** Uma circunstância com potencial de causar impacto adverso.
- **Risco:** A probabilidade de uma ameaça explorar uma vulnerabilidade e o impacto resultante.
- **Tríade CID:**
  - **Confidencialidade:** Acesso apenas por pessoas autorizadas.
  - **Integridade:** Impedir modificações indevidas.
  - **Disponibilidade:** Garantir que sistemas estejam disponíveis.
- **Princípio do Menor Privilégio:** Acessos estritamente necessários para as funções.
